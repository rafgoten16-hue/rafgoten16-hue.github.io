Règles de confidentialité

Dernière mise à jour : 26 octobre 2026.

Clipper est une application personnelle installée sur l'ordinateur de son utilisateur. Cette page explique quelles données Clipper utilise quand on relie un compte YouTube.

Données utilisées

  • Envoi de vidéos (portée youtube.upload) : Clipper envoie sur la chaîne les clips que l'utilisateur a validés, avec leur titre, leur description et leur date de publication.
  • Lecture de la chaîne (portée youtube.readonly) : Clipper lit le nom de la chaîne et l'état des vidéos qu'il a envoyées (privée, publique, nombre de vues, de likes et de commentaires).
  • Statistiques (portée yt-analytics.readonly) : Clipper lit le pourcentage moyen regardé de ces vidéos.

Où sont gardées ces données

Toutes les données restent sur l'ordinateur de l'utilisateur : le jeton d'accès à YouTube et les statistiques sont enregistrés dans le dossier de Clipper. Clipper n'a pas de serveur : aucune donnée n'est envoyée ailleurs que vers les services de Google eux-mêmes.

Partage

Les données ne sont ni vendues, ni partagées, ni utilisées pour de la publicité. L'usage des données reçues des API Google respecte le Règlement sur les données utilisateur des services d'API Google, y compris les exigences d'utilisation limitée.

Retirer l'accès

L'accès peut être retiré à tout moment depuis la page Applications tierces ayant accès à votre compte de Google, ou en cliquant sur « Déconnecter » dans la page Publier de Clipper (le jeton est alors effacé du PC).
